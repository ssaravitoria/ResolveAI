# 🤖 ResolveAI — Agente Inteligente de Atendimento

Meu primeiro agente de Inteligência Artificial, desenvolvido com **Bolt.new e assistência de IA**, como projeto de aprendizado e portfólio.

O ResolveAI utiliza IA generativa para responder dúvidas com base em uma central de conhecimento, buscando oferecer respostas claras e confiáveis.

## ⚙️ Funcionalidades

- 💬 Chat com inteligência artificial.
- 📚 Central de conhecimento.
- 🧠 Respostas contextualizadas com IA.
- 🕘 Histórico de conversas.
- 📊 Dashboard de acompanhamento.

## 🛠️ Tecnologias

- React e TypeScript
- Supabase e Edge Functions
- Groq API
- Git e GitHub
- Bolt.new

## 📚 Aprendizados

Durante o desenvolvimento, explorei integração com APIs, engenharia de prompts, IA generativa, banco de dados, backend serverless, testes e depuração de erros.

O projeto foi uma oportunidade de aplicar esses conhecimentos na prática e compreender como diferentes tecnologias podem trabalhar juntas para criar soluções inteligentes.
